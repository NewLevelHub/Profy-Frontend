# Лендинг

Источник правды — `index.html` в этой папке. Правьте его здесь, а не копию
где-то ещё: Vite отдаёт `public/` как есть, поэтому файл одновременно и
исходник, и то, что видит посетитель.

Локально открывается по `/landing/index.html` — короткий `/landing/` в dev
перехватывает SPA-фолбэк Vite и отдаёт приложение. На обычном хостинге
`/landing/` работает.

Ссылки внутрь приложения относительные (`/login`, `/register`), поэтому
работают и локально, и в проде, пока лендинг и приложение на одном домене.
Адрес, по которому приложение ссылается сюда обратно, задаётся переменной
`VITE_LANDING_URL`.
