# Profy — редизайн (прототип)

Интерактивный прототип редизайна Profy. Все 10 экранов в одном файле.

## Файлы
- **`Profy Redesign.dc.html`** — сам прототип. Открывается двойным кликом в браузере. Внутри: разметка (template), логика (class Component) и метаданные tweaks.
- **`support.js`** — рантайм, который оживляет `.dc.html`. Должен лежать рядом с html.
- **`uploads/theme.css`, `index.css`, `fonts.css`, `tailwind.css`** — оригинальные дизайн-токены проекта (цвета, типографика, радиусы, тени). Источник правды для интеграции в реальный код.
- **`uploads/*.png`** — исходные скриншоты текущего приложения (для сравнения).

## Экраны (в одном файле)
Вход → Выбор цели → Вопрос диагностики → «Молодец!» → Интро блока → Дашборд (Главная) → Результаты → Программа → Профиль → Университеты.
Внизу — панель быстрого перехода между экранами (для ревью).

## Как открыть
Открой `Profy Redesign.dc.html` в браузере (Chrome/Safari). Либо в VS Code: правый клик → Open with Live Server, или расширение для превью HTML.

## Дизайн-токены (из uploads/theme.css)
- Бренд: `#7C3AED` (hover `#5B21B6`), акцент-оранжевый `#EA580C`, success `#22C55E`
- Фон страницы: `#F5F3FF`, поверхности: `#FFFFFF`, сайдбар: `#F0ECFF`
- Текст: `#1E1B4B` / `#4B5563` / `#9CA3AF`
- Шрифт: **Nunito** (400–900)
- Радиусы: 10 / 16 / 22 / pill, тени из `--shadow-card` / `--shadow-button`

## Интеграция через Claude Code
1. Открой папку в VS Code.
2. Запусти Claude Code в этой папке.
3. Пример запроса: «Перенеси экран Профиля из `Profy Redesign.dc.html` в наш React-проект, используя токены из `uploads/theme.css`». Разметка и инлайн-стили читаются напрямую — переноси значения как есть.
